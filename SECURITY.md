# Reporting security problems

Do not attach keys, QR codes, session directories, runtime configuration, databases or real chat content to a public issue. Use GitHub's private vulnerability reporting if the repository exposes that feature. Otherwise contact the maintainer through the [Mahdhi profile](https://www.linkedin.com/in/m4hdhi/) to arrange a private channel before sharing sensitive details.

This software is an independent unofficial integration. Keep the helper bound to loopback. There is no supported public multi-user deployment in this release. No vulnerability-response SLA or public-directory approval is claimed.
