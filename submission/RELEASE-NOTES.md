# 2.2.0 release notes

Adds on-demand permitted-message reading for ChatGPT analysis without an OpenAI API key. Adds separate raw-message sharing consent, bounded pagination and capture-coverage notices. Makes API background analysis optional and disabled by default. Preserves linked-device sessions and existing permission scope during upgrade. Conversation analysis does not save tasks or schedule reminders.

This is a private local distribution release, not an approved OpenAI public-directory release.
